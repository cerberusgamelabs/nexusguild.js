# Changelog

## 0.1.0

- Initial public SDK scaffold for NexusGuild.js
- Added bot-token REST API wrappers for the current `/api/v1` bot API
- Added gateway wrapper for `/bot-gateway`
- Added `REACT_ADD` and `REACT_REMOVE` gateway/webhook event support
- Added interaction context helpers for slash commands and button clicks
- Added portal/session-auth client for bot management, command registration, and webhook subscriptions
- Added public client helpers for public bot info and webhook execution
- Added webhook signing and verification utilities
- Added beginner-oriented README examples and exported constants
